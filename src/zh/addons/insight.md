# NX Insight

NX Insight 是官方[[~addon|插件]]，显示从您的用户到您的[[~node|节点]]的哪些路径仍然可用。
一条路径就是一个客户端网络（运营商，按其 ASN）、一个节点和一个 [[~inbound]]。Insight
显示每条路径的状况，在路径被封锁或审查者开始探测某个节点时发出告警，并把对每个网络可用的
链接排在该网络用户订阅的前面。本页介绍它的前提条件、安装、各个页面，以及什么内容会发送到哪里。

## 前提条件 {#what-it-needs}

- 面板和节点需为 **v0.1.3** 及以上。节点负责统计，面板负责转发。旧版本的节点继续正常服务，
  只是不上报任何数据，Insight 会把它显示为不支持。
- 在 Insight 读取之前，所有节点上的统计都是关闭的。第一次读取会开启统计；最后一次读取十分钟后，
  或者 Insight 的令牌被删除或失去权限时，统计会立即关闭。没有插件时不会统计任何内容。

## 留在您服务器上的内容 {#what-stays-on-your-server}

节点从不上报客户端地址，只上报其 /24（IPv4）或 /48（IPv6）网段。面板转发这些数据而不保存。
Insight 在读取时立即把每个网段转换为运营商和地区，只保存运营商、国家和地区。面板和 Insight
都不会在任何地方写入客户端的地址或网段前缀。

把 Insight 安装在面板所在的服务器上，这些网段就完全不会经过互联网。

## 安装 {#install}

在面板中：**插件 → 浏览 → NX Insight → 安装**。面板会提出问题，然后把它安装在自己的服务器上
或通过 SSH 安装到另一台服务器，或者给您一条命令来运行。所有安装方式见 [[directory]]。

| 问题 | 设置的内容 |
| --- | --- |
| 端口 | 默认 `8099`。开启 HTTPS 时，这是 Insight 唯一的端口。 |
| 数据库 | SQLite，或 PostgreSQL 及其连接字符串。 |
| 第一个管理员 | 名称和 10 个字符到 72 字节的密码。 |
| 管理后台路径 | Insight 提供的一切都在此路径下。随机生成；留空则为根路径。 |
| 公网地址 | 打开 Insight 的地址：协议、主机和端口。 |
| HTTPS | `panel`、`acme`、`acme-http`、`self-signed` 或 `off`，与所有插件相同（[[directory#https-for-the-addon]]）。 |
| 受信任的反向代理 | 仅在反向代理之后使用：其地址或地址段。留空则不信任任何 `X-Forwarded-For`。 |
| 监听地址 | 留空：所有网卡。仅在同一服务器上的反向代理之后使用 `127.0.0.1`。 |
| 区分地区的国家 | 默认 `IR,RU,CN`。这些国家的客户端还会显示省份或州；其他国家的客户端只显示网络和国家。 |
| Telegram 机器人、聊天、代理和 Bot API 地址 | 告警发送到哪里。留空：告警只保存在 Insight 中。Bot API 地址填 `https://tapi.bale.ai` 则通过 Bale 机器人发送。 |
| 告警语言 | 英语、波斯语、俄语或中文。 |

手动安装，在 Linux 服务器上以 root 运行：

```bash
sh install.sh --method docker --opt port=8099 --opt admin_password=… \
  --panel-url https://panel.example.com --claim-code …
```

`--method script` 改用 systemd 而不是 Docker 运行程序。再次运行同一条命令会原地更新；
`--uninstall` 将其移除，`--purge` 还会删除其数据。

批准 Insight 时，它会请求三项权限：读取节点统计的数据（这会开启统计）、排列所有订阅的链接，
以及读取节点地址以显示每个节点的托管位置。

### 登录 {#sign-in}

使用公网地址加管理后台路径登录。Insight 有自己的管理员，而不是面板的管理员。在**安全**中开启
两步验证登录。忘记密码时在服务器上重置：

```bash
insight admin reset-password -user admin -pass …
```

## 概览 {#overview}

页面顶部显示 Insight 是否正在读取面板：

| 状态 | 含义 |
| --- | --- |
| 等待中 | 尚未在面板中注册。 |
| 读取中 | 正常工作；旁边显示最后一次读取的时间。 |
| 不支持 | 面板版本低于 v0.1.3。请先更新面板，再更新节点。 |
| 无权限 | Insight 的令牌缺少读取权限。请在**插件**中重新批准其权限。 |
| 失败 | 最后一次读取失败；Insight 每分钟重试一次。 |

下面是：

- **被切断的网络。** 当到某个运营商的所有路径同时在两个或更多节点上失效时，被封锁的不是您的
  节点，而是该网络被切断了：断网，或只放行部分网站的白名单。Insight 只提示一次，并且不建议
  更换任何东西。
- **被封锁的路径**，每条都附有对同一网络仍可用的路径。
- **矩阵**：纵向为客户端网络（或地区），横向为节点和 inbound，时间范围为过去一小时、六小时、
  一天或一周。每个格子是该网络连接中成功通过的比例。将指针移到格子上可查看数字：连接数、
  已认证数、握手失败数、几秒内被切断的会话、往返时间。

## 节点 {#nodes}

每个节点根据其地址所在的托管网络。如果网络数据库把某个节点归错了位置（服务商的地址段、
前置之后的地址），在这里更正；更正在数据库后续更新后仍然保留。

## 探测 {#probing}

审查者在封锁服务器之前常常先测试它：重放它从真实客户端看到的握手，或在真实用户连接后立即
尝试该端口。节点会统计这些迹象，但不会对其作出任何反应，因此探测者无法从统计中得知任何信息。

每个节点和 inbound 都会得到过去六小时内 0 到 100 的评分。每次重放握手加 20 分，最多 80 分；
真实客户端从不会把同一个握手发送两次。真实用户会话之后紧接着大量握手失败加 20 分。达到 40 分
时会发送告警，并说明应该怎么做：在被封锁之前更换该 inbound 的端口或 SNI（REALITY 还需更换
目标网站），或为节点换一个地址。**之后被封锁？**一栏表示告警后 48 小时内该 inbound 上是否有
路径受阻。

[[protocols/ingress|ingress]] 上的未知 SNI 计数和 Hysteria2 端口范围上的无效 QUIC 数据包计数
显示在评分旁边，但不计入评分：它们是扫描器，而不是对该端点的探测。

## 告警 {#alerts}

所有变化，最新的在前：路径受阻或恢复、网络被切断或恢复、端点正被探测。每条路径都与其自身在
一周中同一小时的正常水平比较，该水平从历史中学习得到；一条路径需要几个小时的流量才能被判断，
并且需要间隔五分钟的两次异常检查才会告警。如果安装时设置了 Telegram 或 Bale 机器人，每条告警
也会以安装时选择的语言发送到那里。

## 订阅：最佳链接在前 {#subscriptions-best-link-first}

对于在两个或更多节点上出现的每个运营商，Insight 会告诉面板哪些节点和 inbound 对它效果最好，
面板会把这些链接排在从该网络获取的[[~subscription|订阅]]的前面。不会删除任何内容：用户仍然
得到所有链接，只是顺序更好。顺序随路径变化而更新，六小时未更新即过期，因此移除 Insight 后，
所有订阅都会恢复面板自己的顺序。某个网络被切断期间，其顺序保持不变。

## AI 分析 {#ai-analysis}

可选：您自己的 AI 模型每天为每个客户端国家读取一次您的路径，在该国出现告警后再读取一次，并
说明它看到的情况：某个协议对某个运营商被封锁、某个节点的地址被列入名单、把用户迁到哪里、
应该更换什么。在 **AI 分析**页面中设置：

| 字段 | |
| --- | --- |
| API 地址 | 任何兼容 OpenAI 的 API：`https://api.openai.com/v1`、OpenRouter，或您服务器上的 Ollama `http://127.0.0.1:11434/v1`。 |
| 模型 | 小型本地模型解读效果差；建议使用 7B 及以上的模型或云端模型。 |
| API 密钥 | 保存在 Insight 的数据库中，不再显示。本地模型不需要。 |
| 代理 | 用于无法直接访问服务商的服务器。 |
| 每日 token 预算 | 超出后，直到第二天（UTC）都不会发送任何内容。 |

发送的内容：按运营商、节点编号和 inbound 统计的过去 24 小时的计数和比例，以及每个节点的托管
国家和服务商。绝不发送客户端或节点的地址，也不发送节点名称。不会向 NX 发送任何内容。每条结论
都会与提供给模型的数字核对，数字不支持的结论会被忽略，因此猜错的模型只会什么都不显示，而不会
显示错误的内容。

## 数据 {#data}

IP 到 ASN 的数据来自 [iptoasn.com](https://iptoasn.com)。IP 地理位置由
[DB-IP](https://db-ip.com) 提供，许可为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。
每个安装都会自行下载这两份数据：网络数据每天更新，地区数据每月更新。

Insight 保存七天的每小时数据和 90 天的每日数据。
